# 🌎 IA: Salve o Planeta

Experiência web educativa e gamificada sobre **Inteligência Artificial e Meio Ambiente**.
O jogador assume o papel de um *Guardião Ambiental Digital* e usa decisões baseadas em IA para recuperar uma cidade com problemas ambientais.

## O que o projeto tem
- Mini game com 4 situações (poluição do ar, água, desmatamento e energia)
- Cidade em SVG que muda visualmente conforme as decisões
- Indicadores: Natureza, Energia e Qualidade Ambiental
- Seções educativas: o que é IA, como ela aprende, cards interativos
- Seção "Mas a IA também tem um custo..." com balança interativa
- Quiz "Você consegue descobrir?", glossário e conclusão

## Tecnologias
HTML, CSS e JavaScript puros. Sem frameworks, banco de dados ou login.
